# Public landing-page audit and implementation plan

The current live page and actual ClearHome route were inspected. The existing labeled, user-driven revision-policy demo, provider limitations, navigation and billing configuration are useful and must remain. The current presentation repeats similarly sized headings, pale surfaces and text-led blocks; it lacks a distinctive visual rhythm.

Plan: preserve the hero demo and pricing; introduce server-rendered editorial sections around the five supplied, unchanged PNGs; use small client Motion islands for headings, graphics and the media rail; add public-logo back-to-top behavior; validate responsive rendering, reduced motion and demo interactions. No authenticated-product changes or deployment.

The supplied artwork includes sample company policies, stylized provider marks and AI bot/star details explicitly approved by the user. Label it as example artwork, explain actual provider capabilities adjacent to it, and keep human approval authoritative. Main posters remain uncropped; only the decorative detail rail uses intentional crops.
