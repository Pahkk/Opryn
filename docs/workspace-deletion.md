# Guarded workspace deletion

Owner control: Settings → Security & Data → Delete workspace. Requires exact workspace name, explicit acknowledgement, and an authentication event within ten minutes. Uses the existing Supabase session and its [documented AMR timestamp](https://supabase.com/docs/guides/auth/jwt-fields), not a browser-provided auth timestamp. Anonymous/direct table deletion remains denied. The RPC repeats ownership checks and performs the final cascade in one transaction. Personal accounts and other workspaces are not deleted.

Deletion now performs cleanup automatically after independent database authorization: cancel pending authorization attempts, disconnect Nango and local integrations using their existing adapters, cancel the workspace subscription, delete workspace-prefixed objects through the Storage API, then atomically delete workspace records. Historical disconnected connections, cancelled attempts and cancelled billing no longer block it. Customer-owned Google documents, personal accounts, Stripe invoices and external provider accounts are not deleted. Cancellation uses `invoice_now:false, prorate:false`; the confirmation explicitly explains cancellation without a prorated refund.

References: [Nango connection deletion](https://nango.dev/docs/reference/backend/http-api/connections/delete), [Stripe cancellation](https://docs.stripe.com/api/subscriptions/cancel?lang=node), [Supabase object removal](https://supabase.com/docs/reference/javascript/file-buckets-remove).

Provider failures return a retryable error with honest partial-cleanup language, not a support prerequisite. Credential references stay until their operation succeeds; missing remote connections are retry-safe. Cleanup is bounded to three minutes/10,000 objects per attempt and is resumed by clicking deletion again, not by a background worker. Slack/Teams/Twilio follow current Opryn disconnect semantics (remove Opryn credentials/access, not uninstall/delete the provider account). A minimal server-only deleted-workspace UUID/timestamp tombstone lets late verified Nango and Stripe callbacks remove newly completed authorizations/subscriptions instead of restoring them. Provider events without the original workspace identity cannot be matched; those still require operational diagnosis.
