# Guided onboarding delivery

## Changes

1. **Flow:** Business (including optional AI setup) → Teach → Review → Ask → Plan → Finish → optional tour or dashboard. AI structure acceptance stays on Business, not another required page.
2. **Routes/components:** Updated `/onboarding` activation components and the shared Guide. No new top-level product pages. Added `source-preview.tsx`, `approval-milestone.tsx`, and `guide-companion.tsx`.
3. **AI setup:** “Set up Opryn for me” submits bounded company name, description, website string, industry, employee count and goal to the existing authenticated, rate-limited suggestion endpoint. No website crawling. Explicit acceptance required. The existing prompt prohibits invented company policy and permissions.
4. **Workspace preview:** Name, industry, team size, goal, suggested/confirmed areas, recommendation, selected source, first finding/approved item and contextual next action. Desktop companion; mobile View/Hide. Only local elements update; inputs are not remounted.
5. **Source previews:** Original silent Motion walkthroughs: connect/share → choose/send → prepare → human review. Clearly labeled Example workflow. Pause, replay and manual step controls. These are illustrations, not recordings of actual provider pages. No preview media download or new dependency.
6. **ChatGPT/Claude:** Reused the Premium entitlement, provider setup, secure request correlation, copy/open handoff, polling and actual processing/review states. Existing provider marks retained. External provider eligibility remains separate from Opryn Premium.
7. **First teach/review/Ask:** Existing source learning and approval endpoints remain authoritative. One process is reviewed before proceeding directly to Ask. The Orb appears only during the actual Ask request; continuation/save does not display an AI Orb.
8. **Feedback:** A small, short cobalt/sky/apricot decorative burst after the first onboarding approval, a live-knowledge status panel, and sourced-answer confirmation. No burst with reduced motion; no animation delays successful actions.
9. **Stripe/trial:** Trial and prices come from the existing billing options. Trial is the main choice; paid comparison is disclosed with Choose a plan instead. Verified subscription state still gates completion. Premium conversation learning still requires its existing entitlement; other sources allow the ordinary value-first flow before billing.
10. **Guide companion:** Original small rounded face, not the corporate logo or a robot. Decorative, silent, and non-looping; slight thinking-state tilt disabled with reduced motion. Corporate/provider logos unchanged.
11. **Guide/tour:** Explicit completion-screen opt-in starts the authorized six-stop tour: Home, Teach, Ask, Knowledge, Needs You, Connections. Skip goes directly to Home. New explicit tours cannot be overwritten by old saved guides. No TTS or audio.
12. **Pointer/spotlight:** Fixed the static pointer left behind on mobile/reduced motion; motion-preference changes hide it. Revalidate connected/visible target after layout settling. Existing route cleanup, target wait, scroll/measure and focus restoration retained. Cobalt outline and ~48% dimming; tour itself is pointer-free.
13. **Motion:** Reused existing Motion components/tokens plus local presence transitions. Existing GSAP remains limited to optional Guide pointer choreography, not ordinary onboarding controls.
14. **Mobile/accessibility:** Compact progress, form before collapsible preview, touch preview controls, existing responsive dialogs, visible focus, decorative face/Orb/confetti and text status feedback. Reduced-motion content remains readable and functional.
